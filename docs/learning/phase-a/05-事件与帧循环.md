## 知识点 1：DOM 事件监听

### 是什么

浏览器通过事件系统通知你「用户做了什么」。`addEventListener` 注册监听器，`removeEventListener` 取消监听。

### 最小示例

```typescript
// 注册
function handleClick(event: MouseEvent) {
    console.log('点击了', event.clientX, event.clientY);
}
document.addEventListener('click', handleClick);

// 取消（必须传入同一个函数引用）
document.removeEventListener('click', handleClick);
```

### 在 F18 项目中的真实用法

```typescript
// 来源：src/vehicleObject/f18/f18InputController.ts
export class F18InputController {

    // 保存函数引用，用于后续取消监听
    private _keydown;
    private _keyup;

    private addEvent() {
        // 注册键盘事件
        // 用箭头函数包装，保持 this 指向
        window.addEventListener('keydown', this._keydown = (e) => { this.keydown(e) });
        window.addEventListener('keyup',   this._keyup   = (e) => { this.keyup(e) });
    }

    private removeEvent() {
        // 取消注册（飞机销毁时调用）
        window.removeEventListener('keydown', this._keydown, false);
        window.removeEventListener('keyup',   this._keyup,   false);
    }
}
```

> ⚡ 关键技巧：把箭头函数赋值给 `this._keydown`，这样 `removeEventListener` 时能传入同一个函数引用。如果直接写 `(e) => this.keydown(e)` 而不保存，就无法取消监听（每次创建的箭头函数是不同对象）。

## 知识点 2：Pointer Lock API（鼠标锁定）

### 是什么

游戏中常见的「鼠标锁定」功能：鼠标被锁定在画布内，移动时不会跑出去，可以无限旋转视角。

### 在 F18 项目中的真实用法

```typescript
// 来源：src/vehicleObject/f18/f18CameraController.ts
private addEvent() {
    // 点击 "Continue" 按钮时请求锁定鼠标
    document.getElementById("play_button").addEventListener('click',
        this._canvasclick = (e) => {
            this.canvas.requestPointerLock();  // 请求锁定
        }
    );

    // 监听锁定状态变化
    document.addEventListener('pointerlockchange',
        this._pointerlockchange = () => {
            if (document.pointerLockElement == this.canvas) {
                // 已锁定：隐藏 UI 面板，开始监听鼠标移动
                document.getElementById("input_panel").style.display = "none"
                document.addEventListener("mousemove",
                    this._rotate3D = (event) => this.rotate3D(event), false
                );
            } else {
                // 已解锁（按 ESC）：显示 UI 面板，停止监听鼠标移动
                document.getElementById("input_panel").style.display = "block"
                document.removeEventListener("mousemove", this._rotate3D, false);
            }
        }, false
    );
}
```

## 知识点 3：Babylon Observable —— 帧循环订阅

### 是什么

Babylon.js 用 `Observable` 模式替代原生事件，提供更强大的订阅/取消订阅机制。`onBeforeRenderObservable` 是最常用的，每帧渲染前触发。

### 最小示例

```typescript
// 订阅
const observer = scene.onBeforeRenderObservable.add(() => {
    // 每帧执行
    mesh.rotation.y += 0.01;
});

// 取消订阅
scene.onBeforeRenderObservable.remove(observer);
```

### 在 F18 项目中的真实用法

项目中**每个模块都有自己的帧循环订阅**，形成一个分布式的帧更新系统：

```typescript
// 来源：src/vehicleObject/f18/f18Physics.ts
private beforeRender;  // 保存 observer 句柄

private addEvent() {
    this.beforeRender = this.scene.onBeforeRenderObservable.add(() => {
        this.render()  // 每帧：物理计算、位置同步、HUD 更新
    })
}

private removeEvent() {
    this.scene.onBeforeRenderObservable.remove(this.beforeRender)
}
```

```typescript
// 来源：src/vehicleObject/f18/f18InputController.ts
private addEvent() {
    // 键盘事件
    window.addEventListener('keydown', this._keydown = (e) => { this.keydown(e) });
    window.addEventListener('keyup',   this._keyup   = (e) => { this.keyup(e) });
    // 帧循环（每帧把键盘状态转换成数值）
    this.beforeRender = this.scene.onBeforeRenderObservable.add(() => {
        this.render()
    })
}
```

```typescript
// 来源：src/physicsScene/airportScene.ts
private addEvent() {
    this.beforeRender = this.scene.onBeforeRenderObservable.add(() => {
        this.render()  // 每帧：水面 UV 偏移动画
    })
}
```

### 一帧内的调用顺序

所有订阅者按注册顺序依次执行：

```
scene.onBeforeRenderObservable 触发
  ↓
AirportScene.render()      ← 水面动画
  ↓
F18Physics.render()        ← 物理计算（每架飞机一次）
  ↓
F18InputController.render() ← 键盘状态转换
  ↓
F18GamepadController.render() ← 手柄轮询
  ↓
F18CameraController.render() ← 相机跟随
  ↓
scene.render()             ← 实际绘制（由 engine.runRenderLoop 触发）
```

## 知识点 4：帧率无关的动画（getAnimationRatio）

### 问题

如果每帧固定移动 `0.1` 单位，在 60fps 的机器上每秒移动 6 单位，在 30fps 的机器上每秒只移动 3 单位。这会导致不同性能的机器游戏体验不一致。

### 解决方案：Delta Time

用「这帧花了多少时间」来缩放每帧的变化量，保证不同帧率下每秒的变化量相同。

```typescript
// 理想情况：
// 60fps → 每帧 16.7ms → deltaTime ≈ 1.0
// 30fps → 每帧 33.3ms → deltaTime ≈ 2.0
// 所以 30fps 时每帧移动量是 60fps 的 2 倍，最终每秒移动量相同
```

### 在 F18 项目中的真实用法

```typescript
// 来源：src/vehicleObject/f18/f18Physics.ts render 方法
let fpsDt: any = this.scene.getAnimationRatio()
// getAnimationRatio() 返回 当前帧时间 / 目标帧时间(1/60s)
// 60fps → fpsDt ≈ 1.0
// 30fps → fpsDt ≈ 2.0

// 推力计算：乘以 fpsDt 保证帧率无关
this.vehicleBody.applyForce(new Ammo.btVector3(
    -this.chassisMesh.forward.x * _speed2 * fpsDt,  // ← fpsDt
    -this.chassisMesh.forward.y * _speed2 * fpsDt,
    -this.chassisMesh.forward.z * _speed2 * fpsDt
), new Ammo.btVector3(0, 0, 0));

// Lerp 插值：也要乘以 fpsDt
let lerp1 = (0.4 * fpsDt) >= 0.99 ? 0.99 : (0.4 * fpsDt)
// 0.4 * fpsDt：60fps 时每帧插值 0.4，30fps 时每帧插值 0.8
// 但要限制在 0.99 以内，防止 Lerp(a, b, 1.0) 直接跳到目标值
```

### Lerp 公式

```typescript
// Lerp(a, b, t) = a + (b - a) * t
// t = 0 → 返回 a（不移动）
// t = 1 → 返回 b（直接到达）
// t = 0.1 → 每帧移动 10%，产生平滑缓动效果

// 来源：f18CameraController.ts
this.tpsFlyCamera.position = BABYLON.Vector3.Lerp(
    this.tpsFlyCamera.position,      // 当前位置
    this.meshCamera.absolutePosition, // 目标位置
    lerp1                             // 插值系数（帧率无关）
);
```

## 知识点 5：事件的正确清理

### 为什么重要

本项目支持多架飞机，每架飞机都有自己的事件订阅。如果销毁飞机时不取消订阅，会导致：
- 内存泄漏（对象无法被垃圾回收）
- 幽灵更新（已销毁的飞机还在每帧执行代码）

### 在 F18 项目中的真实用法

```typescript
// 来源：src/vehicleObject/f18/f18Physics.ts
public dispose() {
    this.removeEvent()              // ← 取消帧循环订阅
    this.f18HUDController.dispose() // ← HUD 也取消自己的订阅
    this.f18SoundController.dispose()
    this.f18AnimationController.dispose()
    this.chassisMesh.dispose(false, false)
    // ... 清理所有资源
}

private removeEvent() {
    this.scene.onBeforeRenderObservable.remove(this.beforeRender)
}
```

### 清理模式总结

```typescript
// 标准模式：每个模块都应该有这对方法
private addEvent() {
    this.beforeRender = this.scene.onBeforeRenderObservable.add(() => this.render())
    window.addEventListener('keydown', this._keydown = (e) => this.keydown(e))
}

private removeEvent() {
    this.scene.onBeforeRenderObservable.remove(this.beforeRender)
    window.removeEventListener('keydown', this._keydown, false)
}

public dispose() {
    this.removeEvent()  // 必须第一步
    // ... 其他清理
}
```

## 小结

| 知识点 | 核心记忆 | 项目中的典型位置 |
|--------|---------|----------------|
| `addEventListener` | 保存函数引用才能取消 | `f18InputController.ts` |
