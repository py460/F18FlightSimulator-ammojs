## 知识点 1：static 静态属性与方法

### 是什么

`static` 修饰的属性/方法属于**类本身**，而不是某个实例。不需要 `new` 就能访问，所有实例共享同一份。

### 最小示例

```typescript
class Counter {
    static count = 0;          // 静态属性：属于类，所有实例共享
    instanceId: number;        // 实例属性：每个实例独立

    constructor() {
        Counter.count++;                // 通过类名访问静态属性
        this.instanceId = Counter.count;
    }

    static reset() {           // 静态方法
        Counter.count = 0;
    }
}

const a = new Counter();  // count = 1
const b = new Counter();  // count = 2
console.log(Counter.count);    // 2（通过类名访问）
console.log(a.instanceId);     // 1
console.log(b.instanceId);     // 2
Counter.reset();               // count = 0
```

### 在 F18 项目中的真实用法

```typescript
// 来源：src/vehicleObject/f18/f18InputController.ts
export class F18InputController {

    // 静态私有属性：存储唯一实例
    private static instance: F18InputController;

    // 静态 get 访问器：获取唯一实例（懒加载）
    public static get ins(): F18InputController {
        if (!this.instance) {
            this.instance = new F18InputController();
        }
        return this.instance;
    }

    // 普通实例属性
    private scene: BABYLON.Scene
    public vehicle: F18Physics
    // ...
}
```

使用方式：

```typescript
// 不需要 new，直接通过类名访问
F18InputController.ins.init(scene)
F18InputController.ins.tergetVehicle(this.flyList[0])
```

## 知识点 2：单例模式（Singleton Pattern）

### 是什么

单例模式保证一个类**全局只有一个实例**。适用于「整个程序只需要一个」的对象，比如：键盘控制器、相机控制器、音频管理器。

### 为什么 F18 项目用单例

```
问题：
  - 键盘事件只有一个（window 上的 keydown）
  - 相机只有一套（当前激活的相机）
  - 如果创建多个 F18InputController，会注册多个 keydown 监听器，导致重复响应

解决：
  - 用单例保证全局只有一个 InputController
  - 任何地方调用 F18InputController.ins 都得到同一个对象
```

### 单例模式的标准实现

```typescript
class Singleton {
    // 1. 私有静态实例（外部无法直接访问）
    private static instance: Singleton;

    // 2. 私有构造函数（外部无法 new）
    // 注意：本项目的构造函数是 public 的（这是一个小缺陷）
    private constructor() {}

    // 3. 公开静态方法获取实例
    public static get ins(): Singleton {
        if (!Singleton.instance) {
            Singleton.instance = new Singleton();
        }
        return Singleton.instance;
    }

    // 普通方法
    public doSomething() { ... }
}

// 使用
Singleton.ins.doSomething();
```

### 在 F18 项目中的四个单例

```typescript
// 1. 输入控制器
F18InputController.ins.init(scene)
F18InputController.ins.tergetVehicle(fly)

// 2. 手柄控制器
F18GamepadController.ins.init(scene)

// 3. 相机控制器
F18CameraController.ins.init(canvas, scene, engine)
F18CameraController.ins.tergetVehicle(fly)
F18CameraController.ins.cameraChange()

// 4. LOD 管理器
F18LODManager.ins.init(rootNode)
```

### 单例的生命周期

```typescript
// 来源：src/game.ts
// 初始化（游戏启动时）
F18CameraController.ins.init(this._canvas, this.scene, this._engine)
F18InputController.ins.init(this.scene)
F18GamepadController.ins.init(this.scene)

// 切换目标（选择驾驶哪架飞机时）
F18CameraController.ins.tergetVehicle(this.flyList[index])
F18InputController.ins.tergetVehicle(this.flyList[index])

// 销毁（重置场景时）
F18CameraController.ins.dispose()
F18InputController.ins.dispose()
```

## 知识点 3：get 访问器（Getter）

### 是什么

`get` 定义一个「计算属性」，访问时像属性一样，但实际执行一段代码。

### 最小示例

```typescript
class Circle {
    radius: number;

    constructor(radius: number) {
        this.radius = radius;
    }

    // get 访问器：访问 circle.area 时自动计算
    get area(): number {
        return Math.PI * this.radius ** 2;
    }
}

const c = new Circle(5);
console.log(c.area);  // 78.54...（不需要加括号！）
```

### 在 F18 项目中的真实用法

```typescript
// 来源：src/vehicleObject/f18/f18InputController.ts
public static get ins(): F18InputController {
    if (!this.instance) {
        this.instance = new F18InputController();
    }
    return this.instance;
}
```

`F18InputController.ins` 看起来像访问一个属性，但实际上每次访问都会执行这段代码（检查实例是否存在，不存在则创建）。

## 知识点 4：静态属性 vs 模块级变量

### 两种全局状态的对比

```typescript
// 方式 1：静态属性（本项目 Controller 单例用这种）
class F18InputController {
    private static instance: F18InputController;
    // 优点：封装在类里，有命名空间
    // 缺点：需要通过类名访问
}

// 方式 2：模块级变量（本项目 f18Global.ts 用这种）
// 来源：src/vehicleObject/f18/f18Global.ts
export let lightClear  // 全局灯光闪烁 interval 句柄

export function setLightClear(val) {
    lightClear = val
}
```

`f18Global.ts` 用模块级变量存储「信号灯闪烁的 setInterval 句柄」，原因是这个状态需要跨多个 `F18Animation` 实例共享（多架飞机共享同一套灯光材质，只能有一个 interval）。

## 小结

| 知识点 | 核心记忆 | 项目中的典型位置 |
|--------|---------|----------------|
| `static` | 属于类，不属于实例，通过类名访问 | `F18InputController.instance` |
| 单例模式 | `private static instance` + `static get ins()` | 四个 Controller |
| `get` 访问器 | 像属性一样访问，但执行代码 | `static get ins()` |
| 模块级变量 | 文件顶层的 `export let` | `f18Global.ts` |
